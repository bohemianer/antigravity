# 🍎 Antigravity - 专为外刊深度阅读定制的极简划词与全能生词本神器 (v1.0.0)

> **极简 · 高雅 · 纯粹 · 跨端漫游**  
> 融合 Claude 暖色纸质美学与 WSJ 华尔街日报权威报刊排版，结合 SuperMemo SM-2 艾宾浩斯记忆算法，支持坚果云 WebDAV 与欧路词典 OpenAPI 全生命周期双向同步。

---

## ✨ 核心特性

- 📰 **外刊沉浸划词**：网页双击或划词即刻触发，精准提取整句原汁原味例句与来源网站 Favicon。
- 🎨 **顶级双语排版**：英文字体采用权威报刊衬线（Charter / Georgia），中文字体首选高清苹方（PingFang SC），饱满舒适。
- 🔤 **多词性智能自动分行**：自动识别 `vt.`、`vi.`、`n.`、`adj.`、`adv.`、`时态:`、`名词:` 等复合释义并整齐分行。
- 🍏 **悬浮糖果胶囊熟练度（SRS）**：未标记默认隐形保持清爽，支持点击展开微胶囊选择器（`⚪未标记` / `🔴陌生` / `🟠学习中` / `🟢已掌握` / `🔵已精通`）。
- 🎴 **艾宾浩斯自测闪卡**：自适应记忆复习算法，支持 `1` / `2` / `3` 极速快捷自测与 `R` 键点读发音。
- ☁️ **全生命周期多端同步**：
  - **坚果云 WebDAV**：双向增量合并与防冲突云端漫游；
  - **欧路词典 (Eudic) OpenAPI**：全部分类生词本双向拉取与删除联动。

---

## 🚀 安装使用指南

1. 下载项目最新 Release 压缩包 `Antigravity-v1.0.0-ChromeExtension.zip` 并解压；
2. 打开 Chrome 浏览器，访问 `chrome://extensions/`；
3. 开启右上角 **「开发者模式（Developer Mode）」**；
4. 点击左上角 **「加载已解压的扩展程序（Load Unpacked）」**，选择解压出的 `AntigravityVocabExtension` 文件夹即可完成安装！
